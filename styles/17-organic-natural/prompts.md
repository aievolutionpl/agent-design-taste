# 17 Organic / Natural — ready prompts

## Codex
```
Build a single-file HTML landing page for "Ziarno" (a stone-milled bread
bakery in Kraków). Style: Organic / Natural — oat background #F6F1E7,
surface #EDE5D4, bark text #2A271F, secondary #5C5647, border #DACFBA,
moss #3D5638 for primary actions (white label), terracotta #A44A26 for ONE
highlight word and one special tag. Fonts: Young Serif 400 for H1–H3 (H1
68px, -0.015em), Figtree 400–600 for body (18px/1.65), labels 13px
uppercase +0.12em. Radius 10/18/28px, pill buttons. Hero: split layout,
headline left, flat SVG illustration (loaf + wheat in earth pigments)
masked in ONE organic blob (border-radius 58% 42% 47% 53% / 52% 46% 54%
48%) with one rotated stamp label. Then a wave-edged surface band with
three process steps and 2.5px round-cap line icons, a menu list with
right-aligned prices in zł, a miller's note card, and an address · hours ·
orders triplet. Quiet SVG paper grain (alpha ≤ .09). No script fonts, no
leaf emoji, no stock photos, no parallax. prefers-reduced-motion reset.
```

## Claude
```
Design an Organic / Natural landing page for Ziarno, a stone-milling bakery.
Warmth must come from specifics — named grain, fermentation hours, real
prices and opening hours — not from beige alone. Young Serif for headings,
Figtree for everything practical. Moss green actions, one terracotta
highlight. Signature move: a single hand-cut blob mask on the hero image,
used once; every other radius is an ordinary soft radius. Rule-break: the
menu and hours are set ruler-straight with hairlines. Deliver one
self-contained HTML file with prefers-color-scheme dark tokens, a
reduced-motion reset, and visible 3px moss focus rings.
```

## Lovable

```
Create an Organic / Natural style landing page for "Ziarno" (Kraków
stone-milled bakery). Rules: oat background #F6F1E7, bark text #2A271F,

illustration, wave dividers between sections, menu with prices, hours and
address cards. No handwritten fonts, no leaf emoji, no blobs on every card,
no light beige text.
```
