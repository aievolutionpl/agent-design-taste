Every agent run, replayable.

tern records what your coding agent read, ran and wrote — then lets you replay the run step by step and diff it against the last one that worked.

01 / how it works

Three commands. No SDK.

tern wraps the agent process, not your code. Nothing to import, nothing to instrument — if it runs in a shell, it can be recorded.

step 01

Record

Prefix any agent command. Files read, commands run and edits made are written to a local run log.

tern rec -- claude

step 02

Replay

Walk the run one step at a time. Every edit is a reversible diff; every command keeps its exit code.

tern replay --step

step 03

Diff

Compare two runs of the same task and jump straight to the step where they diverged.

tern diff run_7a1e run_8f2c

02 / compare

Why not just scroll the logs?

Terminal scrollback tells you what happened. It cannot tell you what changed since the run that worked.
