# Style Combinations

Rule: **1 dominant style + max 1 supporting style.** The supporting style may
only influence isolated layers (typography, one section type, micro-motion) —
never compete on structure.

## Safe pairings

| Dominant | Supporting | How to apply | Example product |
|---|---|---|---|
| Swiss (10) | Minimalism (01) | Swiss grid + minimalist restraint on color | B2B SaaS, corporate |
| Editorial (11) | Brutalism (06) | Magazine typography + raw oversized headlines | Culture magazine, agency |
| Bento (04) | Glassmorphism (02) | Bento layout + glass on ONE highlighted tile | Dev tools, dashboards |
| Y2K (13) | Maximalism (12) | Chrome + layered maximal decoration | Music, streetwear drops |
| Spatial 3D (14) | Minimalism (01) | 3D centerpiece + minimalist everything else | Product launch pages |
| Minimalism (01) | Kinetic Typography (15) | Clean layout, kinetic hero headline only | Portfolio, startup landing |
| Neo-Brutalism (05) | Bento (04) | Hard borders + modular grid structure | Creator tools, Gen-Z apps |
| Liquid Glass (03) | Bento (04) | Fluid surfaces within bento containers | Consumer apps |
| Claymorphism (08) | Minimalism (01) | Puffy 3D accents, restrained palette | Kids education, wellness |
| Skeuomorphism (09) | Swiss (10) | Tactile controls in a strict grid | Audio pro tools, finance |

## Dangerous pairings (avoid)

- **Glassmorphism + Maximalism** — translucency over noise = unreadable.
- **Brutalism + Claymorphism** — raw vs soft = incoherent.
- **Y2K + Minimalism** — nostalgia needs density; starved, it's just weird.
- **Editorial + Glassmorphism** — literary reading flow dies behind blur.
- **Swiss + Y2K** — order vs chaos, no middle ground.

## Mixing rules

1. The dominant style owns: layout, grid, color system, shape language.
2. The supporting style owns at most ONE of: typography flavor, hero treatment,
   motion personality, or a single component family.
3. If you can't name which layer the supporting style owns → drop it.
4. Never mix more than 2 styles. "A bit of everything" is the definition of slop.
