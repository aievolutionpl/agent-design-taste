# Visual Language Foundations

How imagery, texture, light, and icons behave across styles. The style DNA
chooses from this menu; consistency within one project is mandatory.

## Photography
- **Documentary/real**: hospitality, restaurants, local business — real spaces, natural light. Never AI-perfect.
- **Studio clean**: product shots, e-commerce — consistent background, consistent angle.
- **Candid human**: SaaS trust sections — real-looking people mid-action, not posed stock.
- Treatment: pick ONE per project (duotone / natural / warm grade / B&W) and apply everywhere.

## 3D
- Purpose: hero objects, product visualization, spatial UI. Not decoration on every card.
- Coherent material system (one renderer vibe: clay / glass / chrome / matte).
- Slop signal: random abstract "3D blob" floating behind heroes.

## Illustration
- **Flat vector**: education, explainers — consistent stroke weight & palette.
- **Line art**: technical docs, Swiss — 2px stroke, single color.
- **Character**: kids/wellness — one character universe, not random mascots.
- Slop signal: mixing AI-illustration styles page to page.

## Abstract shapes & gradients
- Allowed when they encode brand geometry or depth — with purpose.
- Mesh gradients: max 1-2 per page, low saturation, behind content not over it.
- Grain (noise 2-5% opacity): adds print warmth; works in editorial, brutalist, Y2K.

## Lighting
- Soft studio light → consumer, wellness, clay.
- Hard directional light → brutalist, fashion, dramatic brands.
- Rim/neon light → gaming, Y2K, AI brands (but earns its place).
- None/flat → Swiss, editorial, corporate.

## Iconography
- ONE family per project. Match: stroke weight (1.5-2px), corner radius, fill style.
- Density matched to text: UI icons 20-24px, feature icons 24-32px, always on grid.
- Slop signal: filled Lucide icon next to outlined next to 3D emoji.

## Screenshot treatment
- Real product screenshots > mock UI > nothing.
- Frame: browser chrome or device frame; consistent radius and border across all screenshots.
- Annotate with callouts sparingly (3-5 max per screenshot).
- Never fake dashboard numbers that contradict the page's claims.

## Texture & depth checklist per project
- [ ] One photography treatment
- [ ] One icon family
- [ ] One 3D/illustration system (or none)
- [ ] Grain/texture: consistent opacity
- [ ] Screenshots: consistent framing
